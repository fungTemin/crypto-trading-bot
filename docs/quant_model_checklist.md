# 加密货币量化模型 - 信息清单

## 一、数据层

### 1. 价格数据
- [ ] 多时间周期K线（1m / 5m / 15m / 1h / 4h / 1d）
- [ ] 订单簿深度数据（买卖盘口深度、价差）
- [ ] 逐笔成交数据（tick-level trade data）

### 2. 衍生数据
- [ ] 资金费率（funding rate）
- [ ] 未平仓合约量（Open Interest）
- [ ] 多空比（long/short ratio）
- [ ] 爆仓数据（liquidations）

### 3. 外部数据（可选）
- [ ] 链上数据（活跃地址、大额转账、交易所净流入/流出）
- [ ] 社交情绪（Twitter/Reddit 提及量、Fear & Greed 指数）

## 二、特征工程

### 4. 现有指标（可直接复用）
- EMA、RSI、布林带、ATR、MACD、成交量异动检测

### 5. 需新增特征
- [ ] 波动率特征（已实现波动率、GARCH估计）
- [ ] 动量特征（多周期收益率、横截面排名）
- [ ] 成交量特征（成交量加权价格、成交量分布）
- [ ] 微观结构特征（买卖不平衡度、价差变化率、订单簿斜率）

## 三、模型目标定义

### 6. 预测目标（选一个或组合）
- [ ] 方向预测（涨/跌 分类）
- [ ] 收益率预测（未来N分钟收益率 回归）
- [ ] 夏普比率预测（risk-adjusted return）
- [ ] 预测周期：1分钟？5分钟？15分钟？1小时？

## 四、模型架构

### 7. 模型类型选择
- [ ] 传统ML：XGBoost / LightGBM / CatBoost
- [ ] 时序深度学习：LSTM / Transformer / TCN
- [ ] 强化学习：DQN / PPO

## 五、回测与验证

### 8. 现有回测框架已有
- 历史数据回放、费率感知、PaperExchange模拟

### 9. 需新增
- [ ] 时序交叉验证（防止未来信息泄露）
- [ ] 样本外测试（训练/验证/测试 按时间切分）
- [ ] 特征重要性分析（SHAP / permutation importance）
- [ ] 过拟合检测（训练集 vs 测试集 收益差异）

## 六、执行系统

### 10. 信号融合方式
- [ ] 选项A：模型完全替代现有策略
- [ ] 选项B：模型输出作为信号权重，与现有规则叠加
- [ ] 选项C：模型独立运行，A/B测试对比
